# Narration review

All fourteen Kokoro scene WAVs and the trailer have been transcribed locally using Whisper tiny.en. The transcriptions match the intended capabilities and limitations. Minor transcription differences: Handback sometimes becomes “Hand back”, D-pad joins with a hyphen, “Thirty three” becomes “33”, and “step free” becomes “step-free”. Captions use canonical product spelling with the measured spoken timings. This verifies spoken content via recognition; sound has not been subjectively heard by an audio reviewer.

Engine: original float32 Kokoro-82M, af_heart, speed 0.96. Voice source is synthetic and not a cloned person. No speech service or voice API key was used.
